#  Furniture App

A mobile application prototype for browsing furniture products and exploring UI/UX flows of an e-commerce app.

This project focuses on **frontend structure, navigation, and UI screens**, without backend integration.

---

##  Overview

Furniture App is a **demo / prototype application** designed to showcase:

* Mobile UI/UX design
* Navigation between screens
* Basic user flows (login, browsing, profile, etc.)
---

##  Features

###  Splash Screen

* Displays initial branding

---

###  Authentication (Login / Register)

* Users can input:

  * Username
  * Password
*  No validation or authentication logic
* Any input is accepted

---

###  Navigation

* Fully working navigation between all screens
* Allows seamless movement across the app

---

###  Homepage

* Displays furniture items and content

---

###  Favorites

* Shows a list of favorite items
* Data is hardcoded

 Limitations:

* Cannot add new favorites
* Cannot remove items

---

###  Detailed Screen

* Displays detailed information about a selected item

---

###  Profile

* Displays user profile information

---

###  Console Status

*  No runtime errors
*  Console is clean

---

##  Tech Stack

* Mobile Framework: *React Native*
* Language: *TypeScript *

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/roosmagi/Furniture-App.git
cd Furniture-App
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npx expo start
```
